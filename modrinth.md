# SimpleSit
### Plugin
Its a Simple /sit Plugin with some Customization Options that allows you to sit anywhere you want. **Default config is at the end of this page.**

### Please Message me if you encounter any Bugs!
**Discord: blizzard8562 _(for Bug-Reports, other Issues and Feedback)_**

**Available for Paper and Folia — supports Minecraft 1.21 through 26.2+**

**Features:**
- Sit on stairs and slabs
- Customizable sitting sound
- Customizable sitting particle
- Customizable air-sit message
- Customizable air-sit particle
- `/sit` command
- Permission support
- Configuration reload support
- Folia Support

**How to use:**
- _**Right-click a stair or slab**_ To sit on the block
- _**/sit**_ To sit at your current location
- _**/sit reload**_ To reload the config.yml. _Permission Required: sit.reload_

**Permissions:**

**Player Commands:**_(default permissions)_
- _**sit.use**_ You need this Permission to use the sitting feature.

**Admin Commands:**_(default only for OP)_
- _**sit.reload**_ You need this Permission to run _**/sit reload**_. _(Default: OP)_

_default config.yml_

```
sit-sound: ENTITY_HORSE_SADDLE
sit-particle: CLOUD
air-sit-message: "You cannot sit mid-air!"
air-sit-particle: SMOKE_NORMAL
```
